    Quickstart

    uv run loculus-eternal upload --config loculus-eternal.toml    # publish the loculus dataset
uv run loculus-eternal recover --config loculus-eternal.toml   # anyone can rebuild and verify the whole dataset from Ethereum

    The configuration file names the contract and the blob sources. Full instructions are in the repository's runbook.

    This page verifies the published record against the chain and the configured sources without trusting any of them. It materialises nothing; to rebuild the dataset, run loculus-eternal recover. github.com/JossDuff/loculus-eternal
